# Course Images Directory

This directory contains images for courses and modules.

## Image Structure:
- `course-[id].jpg` - Main course thumbnail images
- `module-[course-id]-[module-index].jpg` - Module-specific images
- `instructor-[instructor-id].jpg` - Instructor profile pictures

## Sample Image Categories:
1. **Web Development**: Code editors, browsers, development tools
2. **Data Science**: Charts, graphs, analytics dashboards
3. **Mobile Apps**: Phone mockups, app interfaces
4. **UI/UX Design**: Design tools, mockups, prototypes
5. **DevOps**: Servers, cloud infrastructure, deployment
6. **AI & ML**: Neural networks, AI interfaces, algorithms

## Recommended Image Sizes:
- Course thumbnails: 1280x720px (16:9 aspect ratio)
- Module images: 1920x1080px (16:9 aspect ratio)
- Instructor photos: 400x400px (1:1 aspect ratio)

## Image Optimization:
- Use WebP format for better compression
- Include alt text for accessibility
- Optimize for web loading speed
